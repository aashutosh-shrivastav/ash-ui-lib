# Ash UI Component Library Design Guidelines
Welcome to the Ash UI Component Library design guidelines. This document outlines the principles, best practices, and standards for designing components within the Ash UI library. Our goal is to ensure consistency, usability, and accessibility across all components.

## Components

### Table
The Table component is designed to display data in a structured format. It supports features such as sorting, filtering, and pagination.
[Link to Table Requirements](./table/requirements.md)

### Form
The Form component provides a way to collect user input. It includes various input types such as text fields, checkboxes, radio buttons, and dropdowns.
[Link to Form Requirements](./form/requirements.md)
### Calendar
The Calendar component allows users to select dates and view events. It supports month, week, and day views, as well as event creation and editing.
[Link to Calendar Requirements](./calendar/requirements.md)
### Charts
The Charts component allows users to visualize data in various chart types. It supports line, bar, pie, and other chart types with features like zooming, tooltips, and legends.
[Link to Charts Requirements](./chart/requirements.md)
